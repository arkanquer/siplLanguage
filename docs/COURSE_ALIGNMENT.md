# SIPL: відповідність практикуму КНУ

Джерело: О. В. Шишацька, А. В. Криволап, А. В. Шишацький, *Теорія програмування. Практикум*, 2024, с. 8–9.
https://csc.knu.ua/media/filer_public/6c/0f/6c0fe915-cb8f-431a-a2a8-f5d353467745/teoriia_programuvannia_navchalnii_posibnik.pdf

## Суворий режим `course`

- Програма: `begin <оператор> end`.
- Оператори: `X := вираз`, композиція через `;`, `if умова then оператор else оператор`, `while умова do оператор`, `begin оператор end`, `skip`.
- Арифметика: цілі числа, змінні, `+`, `-`, `*`, дужки.
- Умови: `=`, `>`, `∨`, `¬`, дужки.
- Назви змінних: одна велика латинська літера (консервативне трактування прикладів з БНФ).

У підручниковій БНФ не задано явного пріоритету операторів; у цій машинній граматиці `¬` має більший пріоритет за `∨`, а `*` — за `+`/`-`. Для уникнення неоднозначності використовуйте дужки. Оператор `;` зв'язує прості оператори; для складених тіл `if` та `while` застосовуйте `begin/end`.

Старий `sipl` CLI зберігає розширення (`/`, додаткові порівняння, короткі програми) і не є суворим режимом курсу.

## Запуск

```bash
python -m sipl.course check examples/course_logic.sipl
python -m sipl.course parse examples/course_logic.sipl
python -m sipl.course run examples/course_logic.sipl
python -m sipl.course trace examples/course_logic.sipl
pytest -q
```

У суворому режимі `∨` обчислюється із коротким замиканням, а `¬` інвертує умову. Вихідний AST є типізованим, `SourceSpan` зберігається; AST-представлення інтегрується з наявним інтерпретатором.

## Обмеження

Формальна БНФ у практикумі не визначає деяких деталей операційної семантики (наприклад, читання невизначених змінних). Тут такі випадки, як і в поточному runtime, завершуються явними помилками. Це рішення інтерпретатора, а не твердження про визначення підручника.
